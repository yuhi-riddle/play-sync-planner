# Important Expense Note Design

## Goal

支払い履歴に、予約番号や当日必要な情報を見返しやすくするための重要メモ扱いを追加する。

## Scope

- 支払い履歴に `is_important` を持たせる
- 支払い追加・編集フォームで「重要メモとして表示」を選べる
- 重要メモには補足文を出す
- 支払い履歴で重要メモを目立たせる

## Out Of Scope

- 支払い証拠画像アップロード
- PDFアップロード
- OCR読み取り
- 購入メール解析
- 証憑管理や承認フロー

## Data Model

`expenses` に `is_important boolean not null default false` を追加する。

既存の `payment_method`、`payment_url`、`memo` はそのまま使う。予約番号、当日必要な情報、購入ページの補足は `memo` に保存する。

## UI

支払いフォームに「重要メモとして表示」チェックを追加する。補足文は「予約番号、当日見せる情報、高額なチケット代など、あとで見返したい支払いに付けます。」とする。

支払い履歴では、重要メモの支払いにラベルを出し、メモ本文を少し目立つ枠で表示する。

## Rationale

画像アップロードだけだと手間が増える。自動読み取りまで作るなら価値があるが、今の段階では重い。まずは支払い履歴の中で、あとから見返すべき情報を目立たせる。
