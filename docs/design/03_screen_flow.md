# Madoi 画面一覧・画面遷移 v1.3

最終更新: 2026-07-03

## 1. 画面設計方針

Madoi は、ホームを操作の入口にします。常時表示の左メニューや下部タブは置かず、各画面では必要に応じて「ホームへ」だけを表示します。

理由:

- このアプリの主な作業は「予定を作る」「候補日時を入力する」「回答状況を見る」「確定する」に絞られる
- 常時メニューが多いと、初期段階では逆に迷いやすい
- ホームを管理画面として使い、そこから必要な画面へ進むほうが直感的

重視すること:

- 今どの日程調整をしているか分かる
- 候補日時が見やすい
- 回答状況がすぐ分かる
- 共有リンクをすぐ送れる
- 複数の日程調整を月表示で見比べられる
- 日付選択や月移動でページ先頭へ戻らない

## 2. 共通ナビゲーション

### ヘッダー

表示内容:

- Madoi ロゴ
- 未ログイン時: ログイン
- ログイン時: アカウント名、通知、設定、ログアウト
- 未読通知がある場合は通知件数を表示する

### ホーム導線

ホーム以外の通常画面では、画面上部に「ホームへ」を表示します。

共有リンク回答画面では、未ログイン参加者が迷わないように「ホームへ」は表示しません。

### フッター

表示内容:

- 利用規約
- プライバシーポリシー

## 3. 画面一覧

### ログイン

パス:

```text
/login
```

目的:

Googleアカウントでログインする。

### ホーム

パス:

```text
/
```

目的:

予定調整の入口として使う。

表示内容:

- 予定一覧への導線
- 予定作成への導線
- 調整カレンダーへの導線
- 設定への導線
- 選択日の予定
- Google Calendar連携済みの場合は、選択日のGoogle Calendar予定
- 対応が必要な通知
- 対応が必要な通知の種類別フィルター

方針:

- ホームでは情報を出しすぎず、今日見たい日付と対応事項に絞る
- 月単位の俯瞰は調整カレンダーに任せる

### 予定一覧

パス:

```text
/events
```

表示内容:

- 予定名
- カテゴリ
- 場所メモ
- 日程調整数
- 管理状態

内部DBでは `events` を使うが、画面上は「予定一覧」と表示する。

### 予定作成

パス:

```text
/events/new
```

目的:

日程調整の元になる予定を作る。

入力内容:

- カテゴリ
- 予定名
- URL
- 場所メモ
- メモ

作成後は、そのまま日程調整作成へ進む。

### 予定編集

パス:

```text
/events/:eventId/edit
```

目的:

予定の基本情報を編集する。

### 予定管理

パス:

```text
/events/:eventId
```

表示内容:

- 予定情報
- カテゴリ
- 場所メモ
- URL
- メモ
- 紐づく日程調整一覧
- 日程調整を始める導線

### 日程調整作成

パス:

```text
/events/:eventId/plans/new
```

目的:

候補日時と回答期限を入力する。

入力内容:

- 候補日時
- 回答期限
- 回答期限前のリマインドタイミング
- メモ

UI方針:

- カレンダーで日付を選ぶ
- 開始時間と終了時間を入力する
- 連日候補を作れる
- 謎解きカテゴリでは 10:00 / 13:00 / 16:00 / 19:00 のテンプレートを使える
- 回答期限もカレンダーUIで選ぶ
- 回答期限が候補日時より後ならエラーにする
- 終日候補を追加できる
- リマインドは、何分前・何時間前・何日前かを任意の数値で複数件入力できる
- ステップ移動時は、次の入力内容の先頭へ戻る

終日候補は、確定後の「Calendarに作成して招待」と手動追加導線でも終日予定として扱えるようにする。

### 日程調整詳細

パス:

```text
/plans/:planId
```

表示内容:

- 予定名
- 日程調整名
- 管理状態
- 回答期限
- 確定日時
- 共有リンク
- 主催者が自分でも回答できるリンク
- 候補日時一覧
- 回答状況
- 参加者一覧
- メモ
- 清算への導線

### 清算

パス:

```text
/plans/:planId/settlement
```

目的:

確定した予定の支払い履歴と清算状況を管理する。

表示内容:

- 支払い履歴追加フォーム
- 支払い履歴の編集・削除
- 支払った人
- 負担者
- 均等割り / 個別金額
- 重要メモとして表示するか
- 清算結果
- 清算残額、支払い済み額、受け取り確認済み額
- 一部清算支払いの記録
- 清算支払いごとの受け取り確認
- 支払い済み額と残額
- 支払い方法メモ
- 支払い用URL
- 支払いURLを開くボタン
- 支払い先メモ設定
- 支払い依頼文面コピー
- 清算リマインド文面
- 清算リマインド送信済み記録

制約:

- 清算支払いが始まる前は、立替支払いを編集・削除できる
- 清算支払いが1件でも記録された後は、立替支払いの編集・削除はロックする
- 清算リマインド文面は、請求額ではなく残額を表示する
- 予約番号や当日必要な情報は、支払い履歴の重要メモとして残す
- 支払い依頼文面には、残額、支払い方法、支払い先URL、メモを含める

外部決済サービスへの直接連携、自動送信は後続Phaseで扱う。保存済みの支払いURLや購入ページURLを開く導線と、手動送信用の依頼文面コピーは表示する。画像アップロードだけの証拠管理は実装しない。

### 日程調整編集

パス:

```text
/plans/:planId/edit
```

目的:

候補日時、回答期限、メモを編集する。

### 調整カレンダー

パス:

```text
/plans
```

目的:

複数の日程調整を月表示で見比べる。

表示内容:

- 月カレンダー
- 候補がある日の件数
- 同じ開始時刻が重なる日の印
- 確定済み候補の印
- 選択日のタイムライン
- 各候補の回答数

操作:

- 日付を選ぶと、選択日のタイムラインだけが切り替わる
- 日付選択ではページ先頭へ戻らない
- 月移動でもページ先頭へ戻らない
- 月またぎの日付を選ぶと、その日付の月へ移動する
- 表示中の年月を押すと、年月選択で直接移動できる
- 土曜・日曜を色で区別する
- タイムラインの候補は開始〜終了で表示する

### 日程回答

パス:

```text
/s/:token/answer
```

目的:

共有リンクから参加者が候補日時に回答する。

入力内容:

- 名前
- 候補日時ごとの ○ / △ / ×
- コメント

未ログインでも回答できる。

### 回答完了

パス:

```text
/s/:token/answer/complete
```

目的:

回答完了を表示する。
回答送信後、主催者にサイト内通知を作成する。

### 日程確定

パス:

```text
/plans/:planId/confirm
```

目的:

主催者が候補日時から1つを選び、日程を確定する。

表示内容:

- 候補日時一覧
- 各候補の回答数
- 参加者ごとの回答状況

### 設定

パス:

```text
/settings
```

表示内容:

- ログイン中のメールアドレス
- 別のメールアドレスを使う場合の案内
- Google Calendar連携状態
- Google Calendar接続、解除

後続Phaseで追加候補:

- 通知設定
- デフォルトリマインド設定

### 通知

パス:

```text
/notifications
```

目的:

対応が必要なことをまとめて確認する。

表示内容:

- 未読通知一覧
- 既読通知一覧
- 未読、既読の切替
- 1件ずつ既読にする操作
- すべて既読にする操作

初期表示:

- 未読のみを表示する
- 既読は「既読」フィルターを押したときに表示する

### 利用規約

パス:

```text
/terms
```

目的:

利用規約のドラフトを表示する。

### プライバシーポリシー

パス:

```text
/privacy
```

目的:

プライバシーポリシーのドラフトを表示する。

Google Calendar連携を追加する前に、取得するGoogleデータと利用目的を明記する。

## 4. 主要画面遷移

### 予定作成から共有リンク送付まで

```text
ホーム
 ↓
予定作成
 ↓
日程調整作成
 ↓
日程調整詳細
 ↓
共有リンクコピー
 ↓
参加者へ共有
 ↓
日程回答
 ↓
回答完了
```

### 回答確認から日程確定まで

```text
ホーム
 ↓
回答受付中の日程調整
 ↓
日程調整詳細
 ↓
日程確定
 ↓
候補日時を選択
 ↓
確定
 ↓
日程調整詳細
```

### 日程確定後の清算

```text
日程調整詳細
 ↓
清算
 ↓
支払い履歴追加
 ↓
清算結果確認
 ↓
清算支払いを記録
 ↓
受け取り確認
```

### 複数調整の確認

```text
ホーム
 ↓
調整カレンダー
 ↓
日付を選択
 ↓
タイムラインで候補を確認
 ↓
日程調整詳細
```

### 通知確認

```text
ホーム / ヘッダー
 ↓
通知
 ↓
対象の予定・清算へ移動
 ↓
対応後、通知を既読にする
```
