# Madoi 画面一覧・画面遷移 v1.2

最終更新: 2026-06-28

## 1. 画面設計方針

Madoi は、ホームを操作の入口にします。常時表示の左メニューや下部タブは置かず、各画面では必要に応じて「ホームへ」だけを表示します。

理由:

- このアプリの主な作業は「予定を作る」「候補日時を入力する」「回答状況を見る」「確定する」に絞られる
- 常時メニューが多いと、初期段階では逆に迷いやすい
- ホームを管理画面として使い、そこから必要な画面へ進むほうが直感的

重視すること:

- 今どの日程調整をしているか分かる
- 候補日時が見やすい
- 回答状況がすぐ分かる
- 共有リンクをすぐ送れる
- 複数の日程調整を月表示で見比べられる
- 日付選択や月移動でページ先頭へ戻らない

## 2. 共通ナビゲーション

### ヘッダー

表示内容:

- Madoi ロゴ
- 未ログイン時: ログイン
- ログイン時: アカウント名、設定、ログアウト

### ホーム導線

ホーム以外の通常画面では、画面上部に「ホームへ」を表示します。

共有リンク回答画面では、未ログイン参加者が迷わないように「ホームへ」は表示しません。

### フッター

表示内容:

- 利用規約
- プライバシーポリシー

## 3. 画面一覧

### ログイン

パス:

```text
/login
```

目的:

Googleアカウントでログインする。

### ホーム

パス:

```text
/
```

目的:

予定調整の入口として使う。

表示内容:

- 予定一覧への導線
- 予定作成への導線
- 調整カレンダーへの導線
- 設定への導線
- 回答受付中の日程調整
- 確定済みの予定
- 最近動いた予定

### 予定一覧

パス:

```text
/events
```

表示内容:

- 予定名
- カテゴリ
- 場所メモ
- 日程調整数
- 管理状態

内部DBでは `events` を使うが、画面上は「予定一覧」と表示する。

### 予定作成

パス:

```text
/events/new
```

目的:

日程調整の元になる予定を作る。

入力内容:

- カテゴリ
- 予定名
- URL
- 場所メモ
- メモ

作成後は、そのまま日程調整作成へ進む。

### 予定編集

パス:

```text
/events/:eventId/edit
```

目的:

予定の基本情報を編集する。

### 予定管理

パス:

```text
/events/:eventId
```

表示内容:

- 予定情報
- カテゴリ
- 場所メモ
- URL
- メモ
- 紐づく日程調整一覧
- 日程調整を始める導線

### 日程調整作成

パス:

```text
/events/:eventId/plans/new
```

目的:

候補日時と回答期限を入力する。

入力内容:

- 候補日時
- 回答期限
- メモ

UI方針:

- カレンダーで日付を選ぶ
- 開始時間と終了時間を入力する
- 連日候補を作れる
- 謎解きカテゴリでは 10:00 / 13:00 / 16:00 / 19:00 のテンプレートを使える
- 回答期限もカレンダーUIで選ぶ
- 回答期限が候補日時より後ならエラーにする

終日候補は、Google Calendar連携と扱いをそろえるためPhase 2で実装する。

### 日程調整詳細

パス:

```text
/plans/:planId
```

表示内容:

- 予定名
- 日程調整名
- 管理状態
- 回答期限
- 確定日時
- 共有リンク
- 候補日時一覧
- 回答状況
- 参加者一覧
- メモ

### 日程調整編集

パス:

```text
/plans/:planId/edit
```

目的:

候補日時、回答期限、メモを編集する。

### 調整カレンダー

パス:

```text
/plans
```

目的:

複数の日程調整を月表示で見比べる。

表示内容:

- 月カレンダー
- 候補がある日の件数
- 同じ開始時刻が重なる日の印
- 確定済み候補の印
- 選択日のタイムライン
- 各候補の回答数

操作:

- 日付を選ぶと、選択日のタイムラインだけが切り替わる
- 日付選択ではページ先頭へ戻らない
- 月移動でもページ先頭へ戻らない
- 月またぎの日付を選ぶと、その日付の月へ移動する
- 表示中の年月を押すと、年月選択で直接移動できる
- 土曜・日曜を色で区別する
- タイムラインの候補は開始〜終了で表示する

### 日程回答

パス:

```text
/s/:token/answer
```

目的:

共有リンクから参加者が候補日時に回答する。

入力内容:

- 名前
- 候補日時ごとの ○ / △ / ×
- コメント

未ログインでも回答できる。

### 回答完了

パス:

```text
/s/:token/answer/complete
```

目的:

回答完了を表示する。

### 日程確定

パス:

```text
/plans/:planId/confirm
```

目的:

主催者が候補日時から1つを選び、日程を確定する。

表示内容:

- 候補日時一覧
- 各候補の回答数
- 参加者ごとの回答状況

### 設定

パス:

```text
/settings
```

Phase 1の表示内容:

- ログイン中のメールアドレス

後続Phaseで追加予定:

- Google Calendar連携状態
- 通知設定
- デフォルトリマインド設定

### 利用規約

パス:

```text
/terms
```

目的:

利用規約のドラフトを表示する。

### プライバシーポリシー

パス:

```text
/privacy
```

目的:

プライバシーポリシーのドラフトを表示する。

Google Calendar連携を追加する前に、取得するGoogleデータと利用目的を明記する。

## 4. 主要画面遷移

### 予定作成から共有リンク送付まで

```text
ホーム
 ↓
予定作成
 ↓
日程調整作成
 ↓
日程調整詳細
 ↓
共有リンクコピー
 ↓
参加者へ共有
 ↓
日程回答
 ↓
回答完了
```

### 回答確認から日程確定まで

```text
ホーム
 ↓
回答受付中の日程調整
 ↓
日程調整詳細
 ↓
日程確定
 ↓
候補日時を選択
 ↓
確定
 ↓
日程調整詳細
```

### 複数調整の確認

```text
ホーム
 ↓
調整カレンダー
 ↓
日付を選択
 ↓
タイムラインで候補を確認
 ↓
日程調整詳細
```
