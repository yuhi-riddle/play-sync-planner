# Madoi 要件定義書 v1.3

最終更新: 2026-06-30

## 1. 概要

Madoi は、友人同士の遊び、謎解き公演、ライブ、飲み会などの日程を合わせるための Web アプリです。

開発プロジェクト名とリポジトリ名は `play-sync-planner` のままですが、画面上のサービス名は `Madoi` とします。

## 2. 目的

まずは「予定を合わせて、確定した予定をスケジュールに入れる」ことに集中します。

イベント作成時に細かい費用や清算情報まで求めすぎると入力が重くなるため、Phase 1 と Phase 2-A では日程調整を優先します。清算や支払い履歴は後続 Phase で実装します。

## 3. 対象ユーザー

- 友人と複数人で予定を立てる人
- 謎解き公演、ライブ、展示、飲み会などの候補日時をまとめたい人
- 複数の調整中予定をカレンダーで見比べたい人
- Google Calendar の予定を見ながら候補日時を決めたい人

## 4. 基本方針

- 日程調整に必要な入力を優先する
- イベント作成時に不要な詳細情報は必須にしない
- 候補日時と回答期限はステップ分割して入力しやすくする
- 候補日時はカレンダー UI で選べるようにする
- 過去日時は候補に追加できない
- 回答期限は最初の候補日時より前にする
- 謎解きカテゴリでは `10:00 / 13:00 / 16:00 / 19:00` の時間テンプレートを使えるようにする
- 共有リンクを踏んだ人は、回答時に名前を入力して参加者になる
- 画面上では `イベント` よりも、必要に応じて `予定` や `日程調整` のような分かりやすい表現を優先する

## 5. Phase 1 実装済み範囲

- Googleログイン
- イベント登録
- イベント編集
- 参加予定作成
- 候補日時登録
- 回答期限登録
- 参加者管理
- 共有リンク生成
- 未ログイン回答
- 日程回答
- 日程確定
- 調整カレンダー
- 利用規約・プライバシーポリシーのドラフト表示

## 6. Phase 2-A 実装範囲

Google Calendar 連携により、候補日時作成・編集画面で自分の予定を確認できるようにします。

取得する Google Calendar 情報:

- 予定の開始時刻
- 予定の終了時刻
- 予定名
- 場所

取得しない情報:

- 予定の説明
- 参加者
- Meet URL
- 添付ファイル
- その他の予定詳細

保存方針:

- Google Calendar の予定詳細はデータベースに保存しない
- 連携用トークンのみ暗号化して保存する
- 予定名と場所は、ログイン中の本人の画面表示にだけ使う
- 共有リンク回答者や他の参加者には表示しない

OAuth スコープ:

```text
https://www.googleapis.com/auth/calendar.events.readonly
```

## 7. Phase 2-A で実装しないもの

- 確定日時の Google Calendar 登録
- 終日候補の UI
- リマインド送信
- 自動候補日時提案
- 参加者全員のカレンダーを集めた自動調整
- Google Calendar 予定詳細のDB保存

## 8. 後続 Phase 候補

### Phase 2-B

- 確定日時を Google Calendar へ登録
- 終日候補の入力
- リマインド設定

### Phase 3

- Walica風清算
- 支払い履歴
- 支払い証拠
- 清算確認フロー

### Phase 4

- LINE / Discord / X 連携
- PWA通知
- 外部共有の強化

## 9. 注意事項

- Google Calendar 連携を追加・変更した場合は、取得するスコープと利用目的をプライバシーポリシーへ明記する
- 予定名や場所を扱う場合でも、本人の画面表示に限定し、他者へ共有しない
- OAuth スコープ変更後は、既存ユーザーに再連携が必要になる
- 正式公開前に、利用規約・プライバシーポリシー・問い合わせ先を見直す
